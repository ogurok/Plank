# Сайт Plank

Готовий лендинг для GitHub Pages: `index.html`, `style.css`, `script.js`, папка `images/` зі скріншотами та іконкою.

## Перед публікацією

Додай у цю папку файл `Plank.apk` (сам APK) поруч з `index.html` — кнопки «Завантажити APK» посилаються саме на нього. Без цього файлу кнопки будуть вести на неіснуючу сторінку.

Скріншоти й іконка вже лежать у `images/` — нічого переносити не треба.

## Публікація на GitHub Pages

1. Створи новий репозиторій на GitHub (наприклад, `plank-site`).
2. Заванти туди всі файли з цієї папки, зберігаючи структуру:
   ```
   index.html
   style.css
   script.js
   Plank.apk
   images/
     icon.png
     favicon.png
     screen1.jpg … screen7.jpg
   ```
3. У репозиторії відкрий **Settings → Pages**.
4. У розділі **Source** обери гілку `main` і папку `/ (root)`.
5. Натисни **Save** — через хвилину-дві сайт зʼявиться за адресою
   `https://<твій-нікнейм>.github.io/<назва-репозиторію>/`.

## Що можна змінити пізніше

- **Версія програми** — рядок «Версія 3.13.0» у секції завантаження (`index.html`, шукай `download-version`).
- **Кольори й неоновий акцент** — усі значення зібрані на початку `style.css` у блоці `:root`.
- **Текст рівнів майстерності** — пороги для «Практика» й «Атлета» на сайті не вказані (на скріншоті їх не було видно), онови їх у `index.html` в секції `#levels`, коли будуть точні цифри.

## Локальний перегляд

Просто відкрий `index.html` у браузері — сторонніх залежностей, крім Google Fonts, немає.
